Storage redesign before production.

The current engine still validates reads through shared conditional updates and serializes publication. This path does not meet the performance brief and will be replaced before production. The replacement uses a native Rust index, immutable journal batches and locally served reads. Native revisioned tables now pass B2, MinIO and local-directory checks, with bounded block reads and disposable caches. Snapshot reads now merge overlapping tables with bounded work and preserve deletions across failures. Checkpointing and the replacement serving path remain under development.
